description: 여러 엑셀 파일을 종합 분석하여 PPT 보고서를 자동 생성합니다. "/excel-to-report"로 실행. 오딧 → 클리닝 → 크로스파일 분석 → 문제점 탐지 → 근본원인 분석 → 차트 시각화 → PPT 보고서까지 원스톱 처리.
allowed-tools: Bash, Read, Write, Glob, Grep, Edit, Agent

excel-to-report 스킬을 실행합니다.

$ARGUMENTS가 있으면 해당 경로의 엑셀 파일들을 대상으로 바로 분석을 시작하고, 없으면 분석 대상 폴더/파일 경로를 사용자에게 물어봅니다.
