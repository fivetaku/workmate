# Operating System

- 이 저장소는 **업무 비서 워크스페이스 OS**다. 단순한 프롬프트 모음이 아니다.
- 모든 것을 `CLAUDE.md` 하나에 몰아넣지 않는다.
- **Commands**는 운영자(사용자) 인터페이스다.
- **Agents**는 역할 인터페이스다.
- **Skills**는 재사용 가능한 능력 인터페이스다.
- **Memory**는 durable(위키) lane과 continuity(daily) lane으로 분리한다.
- 반복 패턴은 자동으로 스킬 후보로 발굴되고, 사용자 승인 후 정식 스킬로 승격된다.
