## 스킬 추가 방법

1. `skill-builder` 또는 `skillers-suda`로 새 스킬 생성
2. **즉시 이 SKILLS_INDEX.md에 행 추가** (트리거, 입력, 출력, 적합 상황 모두 포함)
3. council이 새 스킬을 라우팅에 사용할 수 있게 됨

**주의**: 이 인덱스를 업데이트하지 않으면 council이 새 스킬을 인식하지 못합니다.

## 스킬 후보 (자동 감지)

세션 종료 시 **Stop 훅**이 반복 패턴을 감지해 `_candidates/pending.json`에 후보를 저장합니다. 다음 세션 시작 시 **SessionStart 훅**이 후보를 표시하여 검토할 수 있습니다. 승인 시 → 스킬 생성 → **이 인덱스에 자동 추가**의 흐름을 따릅니다.
