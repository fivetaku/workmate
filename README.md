# workmate — 범용 업무 비서 프레임워크

> 특정 회사·직무에 고정되지 않은 **Claude Code 기반 업무 비서 starter kit**. 데이터 분석, 보고서 초안, 문서 생성, 반복 업무 자동화를 세션 간 맥락 유지까지 포함해 제공합니다.

---

## 무엇인가

workmate는 업무 담당자(자재/구매, 영업, HR, 재무, 마케팅, 기획 등)가 Claude Code에서 쓸 수 있는 **재사용 가능한 업무공간 프레임워크**입니다.

### 핵심 특징

- **도메인 독립**: `data/`, `references/`, `memory/wiki/domain-context/`만 갈아끼우면 다른 업무 비서로 전환 가능
- **자가성장**: 반복 작업을 자동으로 감지해 스킬 후보로 등록 → 승인 시 정식 스킬화
- **연속성 있는 기억**: 3-lane 메모리 (위키 + daily + Unsorted) + 자동 압축 방지 훅
- **모듈화된 룰**: 9개의 rules/\*.md 파일로 역할·정책을 분리, 유지보수 용이
- **한국어 우선**: 응답, 보고서, 메모리 모두 한국어 기본

### 샘플 데이터

> `data/`와 `references/`에 샘플 데이터를 넣어 바로 시험할 수 있습니다. 본인 업무 데이터로 교체하면 나만의 비서가 됩니다.

## 빠른 시작

### 처음 한 번만
```
/onboarding
```
AI가 Q&A로 사용자 맥락(이름, 부서, 업무, 선호 스타일)을 수집합니다.

### 이런 식으로 말해보세요
- **"이 CSV 분석해줘"** — 데이터 탐색 및 패턴 분석
- **"보고서 초안 써줘"** — references/보고서양식.md 양식 적용
- **"주간 브리핑 만들어줘"** — 여러 파일 종합
- **"엑셀로 저장해줘"** — xlsx 파일 생성

### 본인 업무로 전환
1. `data/` 안의 샘플 CSV → 본인 데이터로 교체
2. `references/` → 본인 업무의 용어집/기준값/양식/프로세스로 교체
3. `memory/wiki/domain-context/`에 새 도메인 맥락 페이지 작성
4. 필요하면 `/onboarding` 재실행

rules/, 훅, 메모리 시스템은 그대로 재사용됩니다.

## 폴더 구조

| 폴더/파일 | 용도 |
|-----------|------|
| `CLAUDE.md` | 컨트롤 플레인 (rules/ import) |
| `.claude/rules/` | 9개 모듈화된 정책 문서 |
| `.claude/session/` | 세션 시작 체크리스트 (BOOT.md) |
| `.claude/skills/_candidates/` | 자동 발굴된 스킬 후보 |
| `memory/MEMORY.md` | 위키 인덱스 |
| `memory/wiki/` | durable 지식 (5개 카테고리) |
| `memory/daily/` | 세션 이어받기 메모 |
| `data/` | 현재 도메인 데이터 (샘플 또는 본인 데이터) |
| `references/` | 참조 문서 |
| `reports/` | AI 생성 결과물 |

전체 지도는 [INDEX.md](./INDEX.md) 참고.

## 자가성장 시스템

```
[작업 중 반복 패턴 발생]
       ↓
  [SessionEnd 훅 자동 감지 / 수동 `/wrap`]
       ↓
  pending.json 에 후보 저장
       ↓
  [다음 SessionStart 에 표시]
       ↓
  사용자 승인
       ↓
  skill-builder 로 정식 스킬화
       ↓
  다음부터 한 마디로 실행
```

세션이 길어져 컨텍스트 압축이 임박하면 **PreCompact 훅**이 자동으로 결정/선호/인사이트를 `MEMORY.md ## Unsorted`에 긴급 저장합니다. 다음 세션에서 정식 위키 페이지로 승격됩니다.

## 주요 스킬

전역 스킬을 그대로 사용합니다:
- `data-analyst` — 데이터 분석, 통계, 시각화
- `deep-research` — 웹 리서치 (lite/deep)
- `content-draft` — 보고서/블로그/뉴스레터 초안
- `xlsx` / `docx` / `pptx` — 실제 파일 생성
- `cross-check` — 결과 검증
- `skill-builder` / `skillers-suda` — 반복 업무를 스킬로 자동화

---

## 원칙

1. **한국어 응답**
2. **근거 제시**: 숫자는 출처 파일명 + 집계 근거를 함께
3. **판단은 AI, 결정은 사람**: 확인 필요 사항은 크로스체크 포인트로 명시
4. **양식 준수**: `references/` 에 정의된 양식을 따름
5. **세션 연속성**: 작업 마무리 시 `memory/daily/{오늘}.md`에 이어받기 메모
