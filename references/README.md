# references/

이 폴더는 **업무 기준값, 용어집, 보고서 양식, 프로세스 문서**가 들어가는 곳입니다.

## 현재 상태: 비어 있음

`/onboarding` 실행 시 Phase 4에서 사용자의 실제 문서를 분석하여 아래 파일들이 자동 생성됩니다:

| 파일 | 용도 |
|------|------|
| `기준값.md` | 업종별 핵심 KPI 정상/주의/경고 기준 |
| `용어집.md` | 팀 내부 용어, 약어, 코드 체계 |
| `보고서양식.md` | 보고서 작성 시 따를 구조와 형식 |
| `프로세스.md` | 주요 업무 프로세스 흐름 |

## 자동 생성 방식

1. 사용자가 `00-inbox/`에 실제 업무 문서를 넣음
2. `/onboarding` Phase 3에서 `inbox-sorter`가 분류
3. Phase 4에서 비서가 문서를 읽고 업종·직무를 파악
4. 파악한 내용 기반으로 이 폴더에 기준값·용어집 자동 생성
5. 부족한 자료가 있으면 사용자에게 추가 요청

## 수동 추가

`/onboarding` 없이도 직접 파일을 만들어 넣을 수 있습니다. 비서는 이 폴더의 파일을 우선 참조합니다.
